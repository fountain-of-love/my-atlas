# Inputs

This folder is the intake surface for material that may teach the Atlas about Yves.

Inputs are not canonical source entries and are not outputs. They are evidence-bearing raw material that can be inspected, compared, extracted, and eventually transformed into the person-first source model.

## Suggested input groups

- `older-cvs/` — broad historical CVs and earlier professional material;
- `recent-cvs/` — tailored CVs and current positioning;
- `online-presence/` — websites, profiles, articles, talks, and other public expression;
- `book/` — book drafts, chapters, notes, and related writing;
- `other/` — material that does not yet have a clear home.

The first guided external input is [online presence](online-presence.md). It records a three-pass web discovery process without turning public material into a finished interpretation.

These groups are practical intake lenses, not ontology domains. The same input may reveal patterns, capabilities, ways of working, values, contexts, and evidence.

## Handling rules

- Preserve originals where practical; do not rewrite the input in place.
- Keep sensitive or private material local and untracked unless Yves explicitly chooses otherwise.
- Record enough provenance to locate the source again.
- Treat every source as partial and situated, not as the definitive truth about Yves.
- Do not copy whole inputs into `source/`; extract and link meaningful observations instead.

The first useful input is not necessarily the oldest or most complete. Choose one that offers strong signal and enough context to test the ingestion loop.
