# Model workspace

This is the canonical self-model workspace. It contains source material from which multiple outputs may be derived.

The directories below are provisional domains. They are deliberately allowed to differ: a project does not need the same shape as a person, a skill, or an experience.

## Candidate domains

- [Person](person/README.md)
- [Experience](experience/README.md)
- [Projects](projects/README.md)
- [Skills](skills/README.md)
- [Education](education/README.md)
- [Interests](interests/README.md)
- [People and organizations](people/README.md)

Do not add polished claims merely to fill the structure. Add evidence-bearing material as it becomes available.
