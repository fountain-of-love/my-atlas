# Outputs

Outputs are views over the canonical model. They should be generated or assembled from model entries rather than becoming competing sources of truth.

Possible views include:

- a concise public profile;
- a role-specific CV;
- a technical CV;
- a leadership-oriented CV;
- a personal website;
- an LLM context package;
- a research or collaboration profile.

Each view may select, order, compress, and phrase material differently while preserving links back to the underlying entries and evidence.
