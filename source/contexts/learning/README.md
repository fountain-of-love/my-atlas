# Learning

This branch describes what Yves has learned and acquired, organised by the
learning domains that emerge across his education and courses. It is not a
copy of any one profile or course catalogue: the categories provide context
about the knowledge areas, while the linked course record provides the
source-bound evidence behind them.

The categories are provisional interpretations of the available evidence.
They describe a learning context, not automatically a current capability or
level of mastery.

## Learning categories

- [Data, analytics, and applied AI](data-analytics-and-ai.md) — working with data, statistical analysis, visualisation, prediction, and machine-learning foundations.
- [Software engineering and secure development](software-engineering-and-secure-development.md) — application development, secure coding, application security, and defensive thinking.
- [Enterprise architecture and systems design](enterprise-architecture-and-systems-design.md) — architecture frameworks and the design of coherent, evolvable systems.
- [Process mining and operational insight](process-mining-and-operational-insight.md) — using process data to understand, evaluate, and improve how work flows.

## Evidence base

- [LinkedIn education and course record](../../evidence/education/linkedin-education.md) — the source-bound register of profile-listed education, certifications, and courses; independently unvalidated.

Each category should grow beyond a list of courses when stronger evidence is
available: projects, decisions, artefacts, outcomes, or Yves's own reflection.
