# Evidence

Placeholder for artefacts, outcomes, references, metrics, releases, publications, talks, and other material that supports or qualifies claims in the source model.

Evidence should remain connected to the claim, context, and learning it informs.

## Online-presence evidence

The first online-presence input is split into a source register
([[inputs/online-presence]]), an extraction artifact
([[inputs/online-presence-harvest]]), and a transform queue
([[inputs/online-presence-transform]]). Its observations, identity boundaries,
and lens-contribution routes should become individual evidence objects only as
they are inspected and validated. None of these input artifacts is itself the
canonical evidence register.
