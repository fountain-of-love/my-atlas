# Education evidence

This directory contains evidence and programme context supporting the formal
education and course records in `source/contexts/education/` and
`source/contexts/learning/`.

The evidence pages are not themselves claims that Yves completed a programme.
They preserve provenance, current institutional descriptions, observed course
listings, and the limits of what each source can establish.

## Provenance rule

LinkedIn is treated as an input source and communication location. It is not
treated as the underlying education evidence. The source locations are
registered in [online presence](../../../inputs/online-presence.md#linkedin-source-locations),
then transformed into the evidence registers here.
