# Capability specification

A capability should describe a capacity that can be observed across contexts, not merely a keyword from a CV.

## Optional metadata shape

```yaml
type: capability
related_patterns: []
demonstrated_in: []
skills: []
outcomes: []
evidence: []
```

## Definition

- What does this capability mean in the Atlas vocabulary?
- What distinguishes it from neighbouring capabilities?

## Demonstration

- In which experiences or projects was it used?
- What actions or decisions demonstrate it?

## Range and development

- Under which conditions is it strongest?
- Where is it still developing?

## Evidence and reflection

- What outcomes or artefacts support the claim?
- What has been learned about applying it?
