# Person pattern specification

A person pattern is a recurring way of perceiving, thinking, deciding, creating, relating, or learning.

## Optional metadata shape

```yaml
type: person-pattern
domain: ""
polarity: ""
observed_in: []
related_capabilities: []
evidence: []
confidence: ""
```

## Observation

- What recurring pattern is being noticed?
- In which contexts does it appear?

## Interpretation

- What might this pattern mean?
- What alternative explanations or counterexamples exist?

## Value and tension

- When does the pattern create value?
- When can it become a limitation or enter tension with another pattern?

## Evidence and revision

- What supports the observation?
- What would change or refine the interpretation?
