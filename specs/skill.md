# Skill specification

A skill should be represented as a demonstrated capability rather than a detached keyword.

## Optional metadata shape

```yaml
type: skill
category: ""
related_skills: []
demonstrated_in: []
evidence: []
```

The fields are a starting point, not a required universal schema.

## Definition

- What does this skill mean in the Atlas vocabulary?
- What distinctions keep it from neighbouring skills?

## Demonstration

- In which experiences or projects was it used?
- What actions or decisions demonstrate it?

## Context and range

- Under which conditions is it strongest?
- Where is it still developing?

## Evidence and reflection

- What outcomes or artefacts support the claim?
- What has been learned about applying the skill?
